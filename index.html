01

ValiqAI

Overview

AI coding tools generate features and apps fast, but a lot of that code only looks finished. The UI appears polished, buttons exist, flows seem complete, but the product still has broken logic, silent failures, and accessibility issues. ValiqAI catches the gap between code that appears to work and code that truly works.

The Problem

Traditional testing tools assume developers will write scripts and maintain tests over time. ValiqAI is built for the opposite: people shipping fast with AI who need validation without extra setup. It's the trust layer for AI-built software.

Tech Stack

TypeScript Next.js Playwright OpenAI Node.js

Key Features

  • Automated product scanning from a single URL
  • AI-powered detection of UX, accessibility, and logic issues
  • No test scripts required
  • Reports prioritized by real user impact

02

ChancifyAI

Overview

AI-powered college admissions prediction platform. Instead of vague advice like "you have a good shot," it provides structured evaluation backed by real data. Makes the process more understandable for students who don't have access to private counselors.

How It Works

The platform looks beyond GPA and test scores. It evaluates academics, course rigor, extracurricular depth, leadership, awards, project quality, and essays. Strong applicants aren't just defined by numbers. Context matters. Initiative matters. Impact matters.

Tech Stack

Python Next.js TensorFlow PostgreSQL

Key Features

  • Hybrid prediction using statistical reasoning
  • Essay and profile feedback
  • Nuanced evaluation of extracurriculars
  • Actionable strategy insights

03

DebateXAI

Overview

AI debate coaching and grading platform for speech and debate students, especially Public Forum. Acts like a digital coach, providing personalized feedback in a space where coaching is often limited or unavailable outside of tournaments.

What Makes It Different

Multiple layers: written case analysis with scoring on claim clarity and persuasiveness. Spoken performance evaluation that catches hesitation, pacing, and relevance. Live crossfire simulation where the system engages in back-and-forth practice.

Tech Stack

TypeScript Next.js Speech-to-Text OpenAI

Key Features

  • Written case analysis with structure scoring
  • Speech pattern evaluation
  • Live crossfire simulation against AI
  • On-demand practice anywhere
